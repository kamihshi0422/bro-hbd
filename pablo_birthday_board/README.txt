# パブロ🥦🍼 Birthday Message Board

## 開き方
`index.html` をブラウザで開くと、寄せ書きサイトのプレビューを確認できます。

## 操作
- スマートフォン：左右にスワイプ
- PC：左右の矢印ボタン、キーボードの ← →
- 下部の丸いインジケーターを押して直接移動

## 画像について
アバター画像は、フォーム回答に含まれていたGoogle DriveファイルIDからサムネイルURLを組み立てています。
画像が表示されない場合は、該当するGoogle Drive画像の共有設定を「リンクを知っている全員・閲覧者」に変更してください。
画像の共有設定を変更しても表示されない場合は、Google Drive側のアクセス制限や組織ポリシーが原因の可能性があります。

## 回答の追加について
このファイルは、今回受け取ったExcel回答9件を埋め込んだ試作版です。新しい回答を自動取得する公開版にする場合は、GoogleスプレッドシートまたはApps Scriptとの接続設定が別途必要です。
